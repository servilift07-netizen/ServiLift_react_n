# Documentación técnica de ServiLift v2

Documentación del sistema para el informe del proyecto (tesis). Los diagramas están en
[Mermaid](https://mermaid.js.org/): GitHub los dibuja al abrir cada archivo y se pueden exportar como imagen
desde https://mermaid.live. Las imágenes PNG ya exportadas están en [diagramas/](diagramas/README.md).

| [casos-de-uso.md](casos-de-uso.md) | Actores (roles), diagrama de casos de uso y especificación de los casos principales |
| [modelo-de-datos.md](modelo-de-datos.md) | Diagrama entidad-relación, diccionario de tablas, vistas y máquinas de estado |
| [instalacion.md](instalacion.md) | Puesta en marcha con Docker (base de datos) y uv (backend), variables de entorno |
| [pruebas.md](pruebas.md) | Niveles de prueba, cómo correrlas, cobertura y CI |
| [matriz-rotacion.md](matriz-rotacion.md) | Matriz de rotación de capas y cobertura semanal (bootcamp de pruebas) |
